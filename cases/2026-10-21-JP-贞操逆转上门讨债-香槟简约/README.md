# 2026-10-21 JP 贞操逆转 + 上门讨债（香槟简约风）

- **地区**：JP；**路线**：自定义包装（B），全部用 `X-*` 自定义图层
- **类型**：POV，女借金取り上门讨债 → 壁咚 → 推倒逼婚；三幕 + 三个选项，第三题犹豫不点、直接转场
- **素材**：两条源视频（A = 第一幕猫眼 + 第二幕壁咚 30s，B = 第三幕沙发 13s），中间有模型生成的渐黑，已切掉
- **成品**：主版 + `无BGM版`（用户自配 BGM）+ 两个迭代版本（同台词换角色，`_版本1/2.mp4`）

## 包装
- **配色**：香槟金（取自角色银发）+ 白 + 暗色柔影；全片无框、无气泡，只有片尾下载按钮是实心按钮。
- **字体**：字幕/UI `NotoSansJP-Bold/Black`；标题、数字、片尾大字 `ShipporiMinchoB1-ExtraBold`。
- **开头 ~3s**：失焦背景推镜 + Logo 图标 + `MiraiMindで` + 明朝长标题「貞操逆転世界に / 転移する」，逐帧特效（冲击波、色散、闪白、震屏、粒子、扫光）；之后出「目標：貞操を守り抜け」。不放剧情说明卡。
- **台词**：无框白字 + 柔光晕，小箭头指向脸，跟脸移动（YuNet 人脸跟踪）；每句一个重点词（放大 + 香槟渐变 + 发光 + 弹入）；倒数「3」「2」明朝大字 + 细圆环。
- **溺愛度**：左上，心形 + 明朝数字 + 发光细线，10 → 45 → 90，涨时发光 + 收钱音效。
- **选项**：背景失焦压暗；问题纯文字 + 金色细线；选项 = 明朝序号 + 文字 + 下方细线；指针在选项间犹豫约 2s 再点；选中项香槟色 + 淡光带；顶部「目標」行闪烁强调；ニコニコ风吐槽弹幕每题 7–8 条横向划过（文案在 `gen4.py` 的 `DM`）。
- **AI 聊天手机屏**（片尾前）：照试玩广告 `bubble/lgx` 版式——灵动岛、居中头像 + 「借金取り」+ 在线点、历史气泡（第三幕两句台词）、图片消息、输入中「…」→ 新消息「で、返事は？♡」；配色字体与正片统一。
- **片尾 2.4s**：第三幕笑脸特写压暗做背景，Logo → 明朝「貞操逆転世界」→ 两行文案 → 香槟玻璃下载按钮（4 连点 0.3s）→ 两个等大商店标。

## 声音
- 音效全部来自用户库 `F:\钟海明\音效收集`（弹出、气泡、咔嗒、正确、收钱、闪白、尴尬、空灵），收钱/闪白原文件太小声 +12/+9 dB；只有划屏 whoosh 是合成的。
- BGM：`synth_bgm.py` 原创暗色 R&B，D 小调 96 BPM，各段对齐时间轴；三幕鼓点递进，选项段撤鼓换悬疑 pad。最终用户用了自己的 `音乐.MP3`，选项段仍叠悬疑 BGM。
- 静音：第二幕推主视角处模型生成的错误人声（主版源 A 19.36–20.48s；版本1 18.6–19.95s；版本2 19.46–20.3s），只静 A1，画面照常。
- 成品过 `alimiter=limit=0.89` 防爆音（叠加峰值曾到 +3 dB）。

## 文件
- `gen4.py`：生成全部图层 PNG + `layers.json`（`VER=N` 读 `ver_cfg.py`，输出到 `包装素材_版本N/`）
- `patch.mjs`：幂等写入工程（两条视频分段、定格、静音、X-* 图层、A2 BGM、A3–A6 音效）
- `synth_bgm.py`：按时间轴合成 BGM（鼓组递进 + 选项悬疑段）
- `analyze_ver.py`：迭代版本分析（抽帧、人脸跟踪、ASR、黑场、能量）
- `ver_cfg.py`：每个版本的时间参数（字幕块时间、倒数、静音区间、背景帧）
- `preview4.py`：静帧合成预览，不用导出就能看版面
