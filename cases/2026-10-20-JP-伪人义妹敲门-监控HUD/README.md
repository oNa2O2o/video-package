## 文件
- `gen.py`：全部图层。可复用的函数：
  - `fx()`：广角畸变 + 色散 + 扫描线
  - `draw_chars()` / `float_seq()`：逐字乱码、上浮
  - `box_layer()` / `label_layer()` / `render_tracker()`：识别框、标签，15 fps 逐帧序列
  - `build_subs()`：逐字时间 + 能量校正
  - `meter_values()`：实时跳动数值
  - `choices()`：选项流程
  - `endcard()`：片尾
  - `check()`：跟踪核对图
- `face_track.py` + `lbpcascade_animeface.xml`：逐帧动漫人脸检测、连续性筛选、插值、平滑，人工补点表在 `gen.py build_track()`
- `synth.py`：丝滑音效和微恐 BGM
- `patch.mjs`：幂等写工程（隐藏模板选项轨、`X-*` 轨、音效自动分轨、清理不再使用的 media）

**只作参考**：时间点、文案、黄色、`CAM 01 玄関`、84 歳男性设定都只适用于这条视频，不要照搬。
