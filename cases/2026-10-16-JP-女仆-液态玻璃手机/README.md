## 包装
- **配色**：取画面冰蓝发色 + 藏青女仆装 + 暖琥珀灯光；第二幕转红（`tone: hot`）。字体 `MM Noto JP`。
- **液态玻璃**：gitee `greyd097/yzrt` 的「纯CSS液态玻璃」`.box` 1:1 移植（×2.4）：多层 inset 白高光阴影 + `::before` 暗环 + `::after` 45° 高光 + 外层 `filter: contrast(3)`，`backdrop-filter` 只 blur 1–2px（磨砂大模糊被否决）。代码在 `$APP/src/render/styles/lgx.css`、`ui/lgx.jsx` 的 `LGlass`。
- **标题** `title/lgxsplit`：上半第一幕帧 / 下半第二幕生气帧，斜切分屏 + 玻璃标题条（「ブチギレ」红）+ Logo 胶囊；结束时上半屏铺满接第一幕。
- **台词**：平时悬浮玻璃气泡（`bubble/lgx` FloatChat，最多 3 条，避开底部安全区）；进选项才弹出手机（试玩广告聊天样式：灵动岛、居中头像+名字、左右气泡、渐变用户气泡，无键盘），选中项变成用户气泡。
- **失望度** `meter/lglass`：0→15→30→45→60（第一幕每句一跳）→ 选项一后条飞到画面中央 60→100 → 巴掌溢出 140（液体溢出）→ 选项二时变灰。
- **巴掌**（源 10.54 s，能量峰 + 剪辑点）：画面关键帧震屏、闪白、手机屏裂纹（随后淡去）、拟声字「パァン」；「マジ最低」那句气泡碎裂（Voronoi `Shatter`）。
- **选项一点完**：回复气泡停 ~1.3 s → 手机退场 → 错误音 + 闪烁 + 抖动 → 幕间闪白。
- **选项二超时**（`choice/lgx` `timeout:true`）：倒计时走完 → 手机退场 → 画面变灰 → 「時間切れ」→ 同位置「説得失敗」卡 + 3·2·1（每个 1 s）→ 手指点「リトライ」→ 卡片原地淡出。
- **片尾** `end/lgx` `rewind:true, rewindTo:2.2`：录像带倒带（画面倒放回第一幕害羞帧、黑白→彩色、扫描线、◀◀）→ 从失败卡位置展开成角色卡（图片 = 倒回去的那一帧）→ Logo → 标题 → 名字 + 聊天数 → CTA 连点。

## 声音
- **BGM**：MusicGen stereo-large 生成（`mg.py`，seed 11）→ `bgm5.py` 按时间轴切段拼接（循环中段补长度），超时段压低闷化，片尾段单独接；音量 0.2。
- **打码哔**：1000 Hz 柔和正弦（censor_pi），原声 0–0.52 s 压低。
- **音效**：UI 全部来自用户库 `F:\钟海明\音效收集`（进选项/闪白→弹手机、咔嗒点击、气泡提示、回声弹出、消息提示、收钱、正确提示、空灵）；巴掌/碎裂/错误音 `sfx2.py` 合成；倒带 `sfx_rewind.py`（空灵音效倒放 + 磁带擦音 + 收尾「咔」）。
- 未过 limiter（用户说不用），成片峰值 0 dB。
