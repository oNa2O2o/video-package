## 声音
- 人声：Demucs 分离人声 → 提亮 + 压缩 + 响度统一，原片自带音乐/环境声只留约 1/3。
- BGM：MusicGen stereo-large 分段生成（`mg.py` 思路同女仆案例）→ `bgm_v2.py` 重排：剧情段原音乐 + 人声闪避（说话压到约 30%）；选项段低通压低 + 定格重拍 + 0.27s 滴答/心跳低音 + 上升音推到点击 + 点击重击。
- 音效：沿用贞操逆转案例（用户音效库）。成品过 `alimiter=limit=0.89`。

## 用户的修改过程
1. 不要数值 → 全片吐槽弹幕，从角色身后过
2. 人声听不清、选项不要提问 → 删提问、压 BGM
3. 人声仍听不清；选项要小、中下方、不全屏模糊、加倒计时、过渡缩短；BGM 跟选项节奏 → 人声分离增强 + 新选项样式 + BGM v2
4. 最后一题选项文案改了又改回（文案问题，编剧 skill 处理）

## 踩过的坑（问题 → 怎么改）
- 弹幕烘焙进 V1（`bake_dm.py`），编辑器里改不了 → 应照 1年ぶり 案例用逐帧图层，保持可微调
- 人声被原片自带音乐和 BGM 盖住 → Demucs 人声分离增强 + BGM 在台词处闪避
- 选项照搬香槟案例的全屏失焦 + 提问 + 6s 定格 → 中下方小胶囊 + 倒计时条、无提问、定格 2.5–3.2s
- BGM 只是按段拼接，不跟选项节奏 → 加定格重拍、倒计时滴答、上升音、点击重击
- 正片下方车道的弹幕被主视角的手挡住 → 有手入镜的 POV 片子，弹幕车道避开手的区域
