# 案例：JP · 女性向 · 签售会POV（C 路线：网感剪辑，不用编辑器，同脚本 5 角色）

## 基本信息
- 地区 JP，女性向，**C 路线**（用户：「不用编辑器，你直接包装就行」），PIL + ffmpeg 直接出片，1080×1920，每条 27.9 s。
- 结构：开场语气 1.15 s（「え、やばい…！」+ 推镜 + 抖动大字）→ 签售会 POV 快切 + 口播大字 → 定格缩进手机 → 划卡 / 聊天 UI（转化承接）→ 尾板 6.8 s（Logo 首帧在顶部、5 张卡扇形飞入、卡底聊天数、主角卡粉色高亮、口播、5.5 s 点击）。
- 口播：克隆音色「日语可爱竹马」逐句生成 t0–t7；口播总线侧链压 BGM。
- 工程：`F:/钟海明/2026/2026年11月4日MM-JP-女性向-签售会POV`（`工作/{scripts,specs,ui,stills,tmp}`、`导出/`、`成品/`）。角色 A=蓮 B=陽向 C=律 D=奏 E=湊（`specs/chars.json`）。

## 脚本（本目录）
| 文件 | 作用 |
|---|---|
| `render_v2.py <spec> <out> [--stills t1,t2]` | 正片：镜头剪辑、推镜、大字（`shake` 抖动）、顶部 Logo、定格缩进手机、划卡/聊天 UI |
| `render_end_v2.py <角色> <out> [--stills …]` | 尾板：5 卡扇形 + 聊天数（完整数字千分位，飞入时滚动、之后每 0.28 s 跳涨）+ Logo + 按钮 |
| `assemble_v3.py <spec> <main> <out> <尾板>` | 拼接正片 + 尾板，混口播（侧链压 BGM）、音效、BGM 淡出 |
| `make_ui_cfg.py <主角> <卡1> <卡2> <out>` | 多角色：生成划卡/聊天 UI 配置 |
| `contact_sheet.py` / `gen_bgm.py` | 拆片联系表 / ElevenLabs 生成 BGM |
| `specs/v3_E.json` | 湊版完整 spec（shots / caps / vo / bgFrame / swipe / chat）；其他角色只换 shots 源和 UI |

## 踩过的坑（问题 → 怎么改）
- 未验收就放进 `成品/` → 预览一律放 `导出/预览vN_<角色>.mp4`，验收后才复制到成品和投放目录。
- 开头直接进叙事太快 → 先加 1 s 左右语气词钩子；抖动大字按最大位移算边界（170 号字左侧出画 → 116 号 + 抖动 10 px）。
- 剪辑段和尾板上方空一大块 → 顶部放 Logo；尾板 Logo 第一帧就在，动画只做在卡片上。
- 聊天数写成「112.3万」→ 用户要日语本地化：完整数字 + 千分位（1,240,994），不用中文单位。
- 尾板口播「听着没说完」改了三次：真正原因是 BGM 和尾板音效盖住了末字 → 口播期间压 BGM、降尾板音效、BGM 在口播结束后才淡出，用 whisper 核对末字；之后用户反馈的「还没说完」是播放器问题 → 改之前先确认用户看的是哪个文件、用什么播放。
